# 云端定时任务指令

在 [Claude Code 网页版](https://claude.ai/code) 创建定时任务时，**仓库选你自己的这个仓库**，每个启用的频道建一个任务，指令照下面的格式写，把 `<频道id>` 换掉即可。流程细节都写在仓库的 `autoreel` 技能和频道的 `brief.md` 里，以后改流程只改仓库，不用改定时任务。

```
使用 autoreel 技能，制作今天的 <频道id> 频道，推送到 clip-日期-<频道id> 分支。这是我安排的每日任务，我授权你推送这个分支（以及频道要求时把 inputs/ 里用过的素材标记为已做并提交到默认分支）。
```

## 内置频道的建议时间（北京时间）

制作时间要比发布时间至少早 30 分钟（CosyVoice 配音需要的时间更长，建议早 45 分钟）。分钟数故意避开整点，整点时云端排队的任务多，容易延迟。

| 频道 id | 名称 | 制作 | 发布（channel.json 的 schedule.publish） |
|---|---|---|---|
| kuaibao | 热点快报 | 08:42 | 视频就绪即发 |
| jiangtou | 一条讲透 | 11:47 | 12:30 |
| lengzhishi | 一分钟冷知识 | 14:23 | 15:00 |
| lishi | 历史上的今天 | 16:41 | 19:00（每次做今天和明天两期） |
| haowu | 好物推荐 | 17:37 | 18:00 |
| dushu | 一分钟读本书 | 20:13 | 21:00 |

## 发布状态检查（可选）

```
只读检查：读取本仓库今天（北京时间）各个 clip-日期-<频道> 分支的 status.json，频道列表见 autoreel.config.json 的 channels。
- 分支不存在：说明这一期没有生成，查看原因，能修就用 autoreel 技能补做并推送。
- 分支存在但没有 status.json：可能插件还没处理，用推送通知提醒我打开自影插件弹窗确认。
- status 为 published：汇总成一句话。
不要修改默认分支，不要删除分支，不要登录任何视频平台。
```

## 小贴士

- 第一次运行时，云端会话推送前可能会请你确认授权，回复「同意，以后每天都可以直接推送」即可。
- 你也可以直接对 Claude 说：「按 prompts/定时任务.md，帮我给 autoreel.config.json 里启用的频道创建定时任务」。
- 手动补做：在任意会话里说「使用 autoreel 技能，补做今天的 kuaibao」。
