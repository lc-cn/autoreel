# 一条讲透 · 找方向与写文案

**找方向**：从今天的热点里挑一条讲透。先读今天「热点快报」的文案：`git fetch -q origin clip-D-kuaibao && git show FETCH_HEAD:caption.txt`（D 是今天的日期）。早报不存在时，就自己选当天最重要的一条。
- 优先选影响面大、普通人关心、有背景可讲的新闻。不选娱乐八卦，不选敏感政治议题。
- 围绕这条新闻补搜背景：来龙去脉、相关数据、各方表态。

**写文案**：分 3–4 段，思路是「发生了什么 → 背景/为什么 → 影响/意义 → 接下来看什么」。
- `tag` 是每段的小标题，不超过 5 个字，例如「发生了什么」「为什么重要」「接下来看」。
- `say` 每段 50–70 字，口语化，把因果讲清楚。
- 另外要写 `topic` 和 `topic_say`：`topic` 是开场大字，不超过 6 个字；`topic_say` 是开场口播里念的话题名。
