# 背景音乐

默认情况下，自影会按频道的语气合成一段柔和的背景乐（`tools/bgm.py`，没有版权问题），不需要放任何文件。

想用更好听的音乐：

1. 到 [Pixabay 音乐](https://pixabay.com/music/) 挑一首（可免费商用、无需署名），下载 mp3。建议选纯音乐、节奏平稳、没有人声的。
2. 放进这个文件夹，文件名用英文或拼音，例如 `news-upbeat.mp3`。
3. 在浏览器插件「频道」页的「背景音乐」里选它（或在 `channel.json` 的 `voice.bgm` 填文件名）。

音乐会自动循环到视频长度、结尾淡出，有人声时自动压低音量。**只能放你有权使用的音乐。**
