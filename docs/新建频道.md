# 新建频道

## 推荐：让 Claude 引导你建

在 Claude Code 里打开你的仓库，直接说：

> 新建一个频道，讲职场沟通技巧

它会使用 `autoreel-channel` 技能，按下面的流程一步步问你：
1. **定位**：主题、给谁看、素材从哪来。
2. **调研**：搜索同类账号的做法、热门话题、可信来源，以及这个领域的合规要求。
3. **结构**：频道名、口号、每期怎么分段、时长、发布时间、口播语气。
4. **配色**：给出 3 套配色，并排出封面对比图让你挑。
5. **生成并校验**：写好 `channel.json` 和 `brief.md`，自动检查格式、时长和颜色对比度。
6. **试做一期**：做一期样片给你看，不满意就接着调。
7. **启用**：你确认后提交到仓库，并帮你建好定时任务（或给出可以直接粘贴的指令）。

改频道、停用频道也一样，比如说「把冷知识频道的发布时间改到晚上 8 点」「停用好物推荐」。

## 手动建

一个频道 = `channels/<频道id>/` 下的两个文件。频道 id 只能用小写字母、数字和下划线。

## 1. 复制一个相近的频道

```bash
cp -r channels/lengzhishi channels/my_channel
```

## 2. 改 `channel.json`

| 字段 | 说明 |
|---|---|
| `id` | 和文件夹名一致 |
| `name` / `slogan` | 频道名、口号，显示在画面顶部和封面上 |
| `label` | 开场画面上分类标签前的文字，如「本期涉及」「知识点」 |
| `hook` | 开场大字的形式：`count`（今日 N 条 + `hook_unit`）、`topic`（稿子里的 topic）、`date`（日期） |
| `intro` / `outro` | 开场和结尾的口播模板。可用 `{name}` `{date}` `{n}` `{topic_say}` `{categories}` |
| `items` | 每期条数范围，如 `[3, 4]` |
| `say_chars` | 每条口播字数范围 |
| `max_seconds` | 视频时长上限 |
| `hashtags` | 固定话题（第一个建议用频道名） |
| `collection` | 发布时归入的合集名，需要先在平台上建好 |
| `schedule.publish` | 插件最早发布的时间（北京时间）；`00:00` 表示视频到了就发 |
| `schedule.days_ahead` | 每次多做几天，例如 `1` 表示今天和明天各做一期，留出余量 |
| `deco` / `src` | 画面左下的装饰英文、来源说明前缀 |
| `theme` | 配色：`flow` 是背景渐变，`glows` 是 4 个光晕色，`mark` 是强调色，`stops` 是封面渐变 |

## 3. 写 `brief.md`

告诉 AI 两件事：**怎么找方向**（去哪里找素材、选什么、不选什么、要几个来源）和**怎么写**（分几段、每段讲什么、`tag` 和 `topic` 怎么写）。可以参考已有频道的 brief。

需要你提供素材时（比如课程讲义、产品资料、自己的观点笔记），在 brief 里写明「只用 `inputs/<频道>/` 里的资料」，并说明做完后怎么标记「已做」。

## 4. 检查与预览

```bash
python3 tools/check_channel.py my_channel --preview /tmp/preview
python3 tools/check_channel.py my_channel --preview /tmp/preview --palette 清新森绿,书卷暖棕,午夜星紫   # 对比几套配色
python3 tools/check_channel.py --palettes   # 列出全部配色预设
```

脚本会检查字段格式、时长估算、颜色对比度、brief 是否完整，并生成竖横封面预览。

## 5. 启用

在 `autoreel.config.json` 的 `channels` 里加上频道 id，提交到默认分支。然后：

1. 在云端手动跑一期：`使用 autoreel 技能，制作今天的 my_channel 频道…`，看看效果。
2. 满意后建定时任务（见 [prompts/定时任务.md](../prompts/定时任务.md)）。
3. 插件设置 →「发布时间」→「刷新频道列表」。

## 画面

所有频道共用同一套竖屏骨架：开场目录 → 逐条讲解（大序号、标签、标题、字幕、进度条）→ 结尾回顾 + 关注引导。每一条的主画面由文案里的 `shot`（分镜）决定：

| 分镜 | 画面 |
|---|---|
| `footage` 实拍 | 按英文关键词从 Pexels / Pixabay 取免版权竖屏视频（需要密钥，见[部署指南](部署指南.md)） |
| `chart` 图表 | 柱状图或折线图，数字逐个长出来，强调项高亮 |
| `map` 地图 | 离线绘制的区域地图，标出地点、高亮国家 |
| `timeline` 时间线 | 2–5 个节点依次出现 |
| `quote` 金句 | 大字逐字出现，重点字高亮 |
| `asset` 你的素材 | `inputs/<频道>/` 里的图片或视频 |
| `text` 文字 | 原来的文字播报画面，任何分镜出错时都会自动退回这里 |

在 brief 里写一段「画面偏好」，告诉 AI 这个频道每类内容配什么画面。分镜的完整写法见 `.claude/skills/autoreel/SKILL.md`；画面代码在 `tools/scenes.py`，HyperFrames 的写法见 [HyperFrames 文档](https://github.com/heygen-com/hyperframes)。
