# 新建频道

一个频道 = `channels/<频道id>/` 下的两个文件。频道 id 只能用小写字母、数字和下划线。

## 1. 复制一个相近的频道

```bash
cp -r channels/lengzhishi channels/my_channel
```

## 2. 改 `channel.json`

| 字段 | 说明 |
|---|---|
| `id` | 和文件夹名一致 |
| `name` / `slogan` | 频道名、口号，显示在画面顶部和封面上 |
| `label` | 开场画面上分类标签前的文字，如「本期涉及」「知识点」 |
| `hook` | 开场大字的形式：`count`（今日 N 条 + `hook_unit`）、`topic`（稿子里的 topic）、`date`（日期） |
| `intro` / `outro` | 开场和结尾的口播模板。可用 `{name}` `{date}` `{n}` `{topic_say}` `{categories}` |
| `items` | 每期条数范围，如 `[3, 4]` |
| `say_chars` | 每条口播字数范围 |
| `max_seconds` | 视频时长上限 |
| `hashtags` | 固定话题（第一个建议用频道名） |
| `collection` | 发布时归入的合集名，需要先在平台上建好 |
| `schedule.publish` | 插件最早发布的时间（北京时间）；`00:00` 表示视频到了就发 |
| `schedule.days_ahead` | 每次多做几天，例如 `1` 表示今天和明天各做一期，留出余量 |
| `deco` / `src` | 画面左下的装饰英文、来源说明前缀 |
| `theme` | 配色：`flow` 是背景渐变，`glows` 是 4 个光晕色，`mark` 是强调色，`stops` 是封面渐变 |

## 3. 写 `brief.md`

告诉 AI 两件事：**怎么找方向**（去哪里找素材、选什么、不选什么、要几个来源）和**怎么写**（分几段、每段讲什么、`tag` 和 `topic` 怎么写）。可以参考已有频道的 brief。

需要你提供素材时（比如课程讲义、产品资料、自己的观点笔记），在 brief 里写明「只用 `inputs/<频道>/` 里的资料」，并说明做完后怎么标记「已做」。

## 4. 启用

在 `autoclip.config.json` 的 `channels` 里加上频道 id，提交到默认分支。然后：

1. 在云端手动跑一期：`使用 autoclip 技能，制作今天的 my_channel 频道…`，看看效果。
2. 满意后建定时任务（见 [prompts/定时任务.md](../prompts/定时任务.md)）。
3. 插件设置 →「发布时间」→「刷新频道列表」。

## 画面

所有频道共用同一套竖屏模板：开场目录 → 逐条讲解（大序号、标签、标题、字幕、进度条）→ 结尾回顾 + 关注引导。改模板请编辑 `tools/gen_hf.py` 的 `build()`；HyperFrames 的写法见 [HyperFrames 文档](https://github.com/heygen-com/hyperframes)。
