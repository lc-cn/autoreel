# 常见问题

### 插件没有按时发布
1. 看插件弹窗顶部有没有提示（令牌、登录、暂停、"超过 20 分钟没有检查"等），点提示后面的按钮处理。
2. 电脑睡眠或 Chrome 关闭期间插件不会运行，恢复后会在 5 分钟内自动补发。
3. 还不行：设置页「运行日志」→「复制」，发给你的 Claude 会话分析。

### 下载视频很慢、经常中断
设置页「下载线路」点「测速」。插件会在「直连 GitHub（令牌认证，支持续传）」和「GitHub API（通常更快，不支持续传）」之间自动选择，断了会续传或换线路。国内网络连 GitHub 较慢属正常，35MB 的视频通常 1 分钟内能下完。

### 弹窗提示"令牌没有写权限"
令牌的 Contents 权限要设成 **Read and write**。发布本身不受影响，但发布结果写不回仓库，旧视频也清理不了。

### 抖音要求短信验证 / 滑块
插件会弹浏览器通知并把发布窗口切到前台，在窗口里完成验证后会自动继续（最多等 10 分钟）。

### 不想发某一条 / 已经手动发过了
插件弹窗里该栏目右边的「⋯」→「标记为已发布」，今天就不会再发。需要再发一次用「重新发布」（会二次确认，避免重复）。

### 想改栏目、时间、音色
- 频道设置：改 `channels/<频道>/channel.json`；音色：改 `autoclip.config.json` 并提交到默认分支，第二天生效。
- 发布时间：插件设置「发布时间」。云端制作时间：改定时任务的时间。
- 新增栏目或改流程：改 `channels/<频道>/` 下的 channel.json 和 brief.md（见 [新建频道](新建频道.md)）。

### 视频号、快手
插件支持，但默认关闭。在设置「发布平台」打开并扫码登录即可。这两个平台的页面适配测试得比抖音少，第一次请盯着发布窗口看一下。

### 云端运行一次大概消耗多少额度
一条视频的搜索、写稿、渲染，按 API 标价约 2–4 美元。用订阅套餐时会从套餐额度里扣，不额外计费。

### CosyVoice 配音太慢
云端没有显卡，一分钟视频的配音大约 6–8 分钟，属正常。可以把定时任务的制作时间提前；或者换成火山引擎（几秒钟就能配完）。

### 想换成抖音上常见的那些配音音色
这些音色大多来自火山引擎豆包语音（和剪映同源）。按 [部署指南](部署指南.md) 第 3 步开通并填好配置即可，`voice.provider` 保持 `auto` 就会自动用火山引擎。
