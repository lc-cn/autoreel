# 部署指南

你需要：GitHub 账号、能用 Claude Code 网页版（云端定时任务）的 Claude 账号、一台常开的电脑和 Chrome、一个抖音账号。

## 第 1 步：创建你的仓库

1. 在本项目首页点 **Use this template → Create a new repository**，**Visibility 选 Private**。
2. 这个仓库既放工具和频道定义（默认分支，一般叫 `main` 或 `master`），也当云端和插件之间的"信箱"：每期成品放在 `clip-日期-频道` 分支，插件只保留最近 7 天，过期的会自动清理。

## 第 2 步：选频道、改配置

编辑 `autoreel.config.json`：

- `channels`：启用哪些频道，例如 `["kuaibao", "lengzhishi"]`。
- `account.name`：你的账号名。
- `voice`：配音方案，见第 3 步。
- `content.trusted_sources`：优先采信的媒体。

每个频道的细节在 `channels/<频道>/channel.json` 里：名称、口号、配色、条数、时长上限、固定话题、发布时间。读书和好物频道需要先在 `inputs/` 里放素材。

## 第 3 步：配音

**方案 A：火山引擎豆包语音（抖音同款音色，推荐有预算的账号使用）**

1. 注册 [火山引擎](https://www.volcengine.com/)，开通「豆包语音 → 语音合成大模型」。
2. 在控制台拿到 **App ID** 和 **Access Token**，在音色列表里选一个音色，记下它的**音色 ID**。
3. `autoreel.config.json` 里填写 `voice.volcengine.app_id` 和 `speaker`，并把 `via_proxy` 改为 `true`。语气：选「多情感」音色时会用 `emotion` 参数表现每段的语气；豆包语音 2.0 音色把 `resource_id` 改成 `seed-tts-2.0`，会改用语音指令。
4. **密钥不要写进仓库。** 打开 Claude Code 网页版，找到这个仓库所用环境的设置，添加一个网络密钥：
   - 主机名：`openspeech.bytedance.com`
   - 请求头：`X-Api-Access-Key`
   - 值：你的 Access Token

   也可以直接对 Claude 说「帮我配置火山引擎语音合成的密钥」，它会弹出安全表单让你填写。

> 火山引擎的接口按 V3 单向流式协议对接（`tools/tts.py` 里的 `_volc_one`）。如果你开通的是别的版本，可能需要调整 `resource_id` 或 `endpoint`。

**方案 B：CosyVoice3 离线配音（免费，默认）**

默认就是这个方案，不用填任何东西。用的是阿里开源的 Fun-CosyVoice3-0.5B（Apache-2.0，可商用），首次运行会下载约 4GB 模型（HuggingFace 很快，通常 1–2 分钟）。云端没有显卡，一分钟的视频配音大约需要 5–6 分钟。

- **音色**：`voice.cosyvoice.voice` 可选「女声」「男声」（`tools/voices/` 下的参考录音）。频道也可以在 channel.json 的 `voice.voice` 里单独指定，例如历史、读书频道用男声。
- **语气**：每段口播可以有自己的语气（平稳、轻快、严肃、沉重、温暖、惊讶、激昂、悬念），AI 写稿时会按内容选。频道的默认语气写在 channel.json 的 `voice.mood`。
- **用自己的声音**：按 `tools/voices/README.md` 加一个音色文件夹（一段 5–15 秒的录音 + 录音文字）。**只能用你本人或已获授权的声音。**

**怎么保证听得清**（三种方案都适用）：
- 逐句合成，长句子自动拆开；句号、问号、省略号后停顿的长短不同，段与段之间停得更久。
- 时长超了只用模型自己的语速参数小幅提速（最多 12%），不再事后硬加速；再长就提醒删稿。
- **字幕和配音分开处理**：稿子按字幕的样子写（`11月12日`、`9970亿`、`6.3%`），字幕原样显示，配音前自动转成读法（十一月十二日、九千九百七十亿、百分之六点三）。自动判断不了的用 `{显示|读法}`，例如 `{11.12|十一月十二日}`。
- 多音字可以在稿子里用 `{行|háng}` 标注读音（CosyVoice3 会按标注读；其他引擎忽略标注，照原字念）。
- **清晰度检查**：每句合成后用离线语音识别转回文字和原稿比对，没念清楚的句子自动换种子重做，最多 3 次，结果写在 `配音检查.json`。可以在 `voice.qc` 里关掉。
- 响度统一到 -16 LUFS，各期音量一致。

## 第 4 步：实拍素材（可选，推荐）

文案里的 `footage` 分镜会按关键词去 Pexels / Pixabay 找免版权竖屏视频。不配也能出片，这些镜头会退回文字画面；图表、地图、时间线、金句不需要任何密钥。

1. 申请密钥（都免费，有一个就行，两个都配素材更多）：
   - Pexels：登录后打开 <https://www.pexels.com/api/>，点「Your API Key」。
   - Pixabay：登录后打开 <https://pixabay.com/api/docs/>，页面里「Parameters → key」处就是你的密钥。
2. 打开 Claude Code 网页版，进入这个仓库所用环境的设置，在**环境变量**里添加：
   ```
   PEXELS_API_KEY=你的 Pexels 密钥
   PIXABAY_API_KEY=你的 Pixabay 密钥
   ```
   **不要写进仓库，也不要发在对话里。** 环境变量在设置里是明文保存的，只用这类免费素材密钥，不要放付费服务的密钥。
3. 如果环境的网络是「受限」模式，还要在允许的主机里加上 `api.pexels.com`、`videos.pexels.com`、`pixabay.com`、`cdn.pixabay.com`。

下载过的素材会缓存在 `/tmp/ziying-footage-cache`，同一个关键词不会重复下载。

## 第 5 步：GitHub 令牌（给浏览器插件用）

GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token：

- **Repository access**：Only select repositories，只选你的这个仓库。
- **Permissions → Repository permissions → Contents：Read and write**
- 其他权限都不用开。

## 第 6 步：云端定时任务

1. 打开 [claude.ai/code](https://claude.ai/code)，选择你的仓库新建会话，先手动跑一期：
   `使用 autoreel 技能，制作今天的 kuaibao 频道，推送到 clip-日期-kuaibao 分支。我授权你推送这个分支。`
   第一次要装依赖、下载模型，耗时较长。成功后你会收到视频、文案和来源链接。
2. 按 [prompts/定时任务.md](../prompts/定时任务.md) 给每个启用的频道建定时任务。也可以直接对 Claude 说：「按 prompts/定时任务.md 帮我创建定时任务」。

## 第 7 步：浏览器插件

1. 把仓库里的 `extension/` 文件夹复制到电脑上一个固定位置，之后不要移动。
2. Chrome 打开 `chrome://extensions`，在右上角打开「开发者模式」，点「加载已解压的扩展程序」，选中这个文件夹。
3. 把「自影 AutoReel」固定到工具栏。
4. 设置页会自动打开：填写 **GitHub 仓库**（例如 `yourname/my-autoreel`）和**令牌**，然后点保存。
5. 在「发布时间」里点「刷新频道列表」，确认读到了你启用的频道。
6. 在「发布平台」里只开你有账号的平台；在「下载线路」里点一次「测速」。
7. 打开插件弹窗，点抖音的「扫码登录」。
8. （可选）在抖音里建好和频道同名的合集；在「消息推送」里配置企业微信、飞书、钉钉、OneBot（QQ）、Bark、Telegram 等通知渠道。

## 日常

- 电脑和 Chrome 开着即可。插件图标出现红色「!」时，点开弹窗看提示。
- 发布时 Chrome 顶部会显示"正在调试此浏览器"，这是插件在模拟键盘输入，属正常现象。
- 有问题见 [常见问题](常见问题.md)。
