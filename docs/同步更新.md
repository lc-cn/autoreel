# 同步自影的更新

你的仓库是用 **Use this template** 建的，和上游 [lc-cn/autoreel](https://github.com/lc-cn/autoreel) 没有共同的提交历史，不能直接 `git merge`。用仓库自带的同步脚本更新。

## 最省事：让 Claude 帮你同步

在 Claude Code 里打开你的仓库，说一句：

> 运行 tools/sync_upstream.py，把自影上游的更新同步过来，先给我看预览

Claude 会先预览改动，你确认后再执行、提交、推送。

## 手动同步

在仓库根目录：

```bash
python3 tools/sync_upstream.py
```

先预览会改哪些文件，不会动任何东西。确认没问题再执行：

```bash
python3 tools/sync_upstream.py --apply
```

最后用 `git diff` 看一遍，提交推送：

```bash
git add -A && git commit -m "同步自影上游" && git push
```

## 会改什么、不会改什么

| 类别 | 文件 | 同步方式 |
|---|---|---|
| 框架代码 | `tools/`、`extension/`、`.claude/skills/`、`docs/`、`prompts/`、`assets/`、README 等 | 用上游版本覆盖 |
| 你的配置 | `autoreel.config.json`、`channels/*/channel.json` | 只补上游新增的字段，你已有的值一个都不改 |
| 你的内容 | `channels/*/brief.md`、`inputs/`、你自己加的频道和音色（`tools/voices/`） | 完全不碰 |
| 上游新增的频道 | `channels/<新频道>/` | 复制过来但不启用；你删掉的内置频道不会被加回来 |

所以**不要直接改框架代码**（比如 `tools/gen_hf.py`），下次同步会被覆盖。想改流程，改 `channel.json` 和 `brief.md`；需要改代码的，欢迎给上游提 Issue 或 PR。

## 同步之后

- 脚本提示「浏览器插件有更新」时：重新下载仓库里的 `extension/` 文件夹，替换你本地加载的那份，然后在 `chrome://extensions` 里点插件的「重新加载」。设置和登录状态会保留。
- 云端定时任务不用改：它每次运行都会读取仓库里最新的技能和工具。
