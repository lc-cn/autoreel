# 内置音色

CosyVoice3 按一段参考录音的音色和语气来合成。这里的两段参考录音由 [CosyVoice-300M-SFT](https://github.com/FunAudioLLM/CosyVoice)（Apache-2.0）的内置音色「中文女」「中文男」生成，可以放心商用。

| 文件夹 | 音色 |
|---|---|
| `女声/` | 清亮的女声，适合资讯、科普 |
| `男声/` | 沉稳的男声，适合深度解读、历史 |

在 `autoreel.config.json` 的 `voice.cosyvoice.voice` 里填文件夹名即可切换。

**加自己的音色**：最方便的是在浏览器插件的「音色」页上传或直接录音，插件会自动转成合适的格式并保存到这里。也可以手动：新建一个文件夹，放一段 5–15 秒、安静环境下录的 `prompt.wav`，和录音逐字对应的 `prompt.txt`。录音的语气会影响成片：想要播报腔就用播报的语气录，想要聊天感就用聊天的语气录。**只能使用你本人或已获授权的声音。**
