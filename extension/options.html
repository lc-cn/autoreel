每 5 分钟检查一次中转仓库，到点自动发布到已开启的平台。Chrome 开着即可。

中转仓库

云端每天把视频、文案、封面推送到这里，插件从这里取。

下载线路

插件按测速结果自动选择：能续传的「直连」和速度更快的「API」，哪条更合适先用哪条，失败自动换另一条。测一次就会记住。

频道与发布时间

频道的启用、发布时间、文案风格、配音语速等都保存在仓库里，到「频道」页查看和修改，保存后云端制作和插件发布都会按新设置来。

备份与迁移

导出全部设置（推送渠道、模板、发布时间等），换电脑或重装插件后导入即可。默认不包含 GitHub 令牌。

登录保活

定时打开已开启平台的后台页面，检查并刷新登录状态。停用的平台不会被检查。

频道

左边选频道，右边是它的设置：发往哪些账号、发布时间、文案风格、配音等。改完点「保存到仓库」，下一期制作就按新设置来。所有频道共用的配音和内容规范在「制作设置」。

制作设置

所有频道共用的制作规则，写在仓库的 autoreel.config.json。单个频道的设置在「频道」页。

内容规范

所有频道共用的找资料和发布规则，写在 autoreel.config.json。

素材

仓库 inputs/ 里给 AI 用的资料：书单、产品资料、图片和视频。需要你提供素材的频道，AI 只用这里的内容。

点「从仓库拉取」读取素材。
音色

CosyVoice 按参考录音的音色和语气来配音（仓库 tools/voices/）。试听、设默认音色；单个频道用哪个音色在「频道」页选。

新增音色

上传或录一段 5–15 秒、安静环境下的清晰录音，并填写录音里逐字说的话。录音的语气会带到成片里：想要播报腔就用播报的语气读。

自动采集

每天 23:10 以后，插件在你的浏览器里打开抖音「数据中心 → 作品分析」，只读取各作品的播放、2 秒跳出、完播、平均播放时长、点赞、评论，写进仓库 history/数据.jsonl。不会发布、修改或删除任何内容。

发布平台

关闭的平台不会被任何操作触发：不发布、不检查登录、不打开页面、不发通知。同一个平台有多个账号时，每个账号用一个单独的 Chrome 用户资料（各自装插件、各自扫码登录），在这里选这个浏览器登录的是哪个账号；频道发往哪些账号在「频道」页设置。插件发布前会核对账号 ID，对不上就不发。

浏览器通知

在电脑右上角弹出。「需要验证」「登录失效」点通知可直接跳到处理页面。

推送渠道

可添加多个，每个渠道单独选择推送哪些事件。消息体是模板：{{变量}} 会按内容类型自动转义，写在 JSON 引号里即可；需要原样插入用 {{变量|raw}}。地址里也可以用变量（会做 URL 编码）。
